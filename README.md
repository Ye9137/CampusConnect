## 2.0 正式版

以下汇总 **从 1.5.0 升级到 2.0.0 的完整更新**，包含 1.5.1、1.5.2 及 2.0 测试阶段累计加入的功能与修复，方便从 1.5 直接升级的用户查看。

### 新增功能

1. **新增有线网络连接模式（Windows / macOS）**：插入网线后可使用校园网认证，无需填写 Wi-Fi 名称，也无需 Wi-Fi 定位授权；有线模式不再调用无线连接流程。
2. **新增明确的连接方式选择（Windows / macOS）**：在设置中直接选择「Wi-Fi 无线网络」或「有线网络（以太网）」，按模式显示相关设置。原有 Wi-Fi 名称留空的配置继续识别为有线网页认证；修改设置后保存才会用于实际连接。
3. **新增四种有线认证入口（Windows / macOS）**：
   - **网页认证**：打开学校原有认证页面，自动填写账号信息并按设置提交。
   - **PPPoE 宽带拨号**：调用操作系统中已创建、已保存凭据的宽带连接；拨号使用的网卡由该系统连接配置决定。
   - **802.1X 系统认证**：复用系统已配置的 EAP、证书及凭据。Windows 向选中的以太网接口请求重新认证；macOS 使用系统描述文件与自动连接，并提供网络设置入口，手动连接在系统设置中完成。
   - **学校专用客户端**：选择并启动已安装的 Windows EXE 或 macOS .app；macOS 客户端已运行时不重复启动。客户端内的账号、验证码及专有认证仍由该客户端处理。
4. **新增网页必选框与协议项自动勾选（Windows / macOS）**：识别登录必选框、协议项及可识别的自定义勾选控件，触发学校网页原有点击事件并等待异步确认；已勾选的不重复点击。记住密码、自动登录、推广订阅等可选项保持原状；勾选被拒绝、禁用或需要人工确认时停止自动提交，验证码等仍需手动完成。
5. **新增程序内问题反馈入口（Windows / macOS）**：左下角显示「如果遇到问题请点击：!」，点击感叹号可展开联系方式，方便联系作者反馈问题。
6. **新增 Windows 界面恢复入口与自动恢复机制**：托盘菜单加入「刷新界面」；从托盘打开、从最小化恢复，或切换到其他程序超过一分钟后返回时自动刷新界面。界面进程退出或卡死时尝试重载、重建浏览器控件，连续恢复失败时显示重试按钮。

### 修复与改进

- **修复有线模式仍显示 Wi-Fi 的问题**：按连接方式更新图标、网络状态、窗口与托盘 / 菜单栏标题，以及连接和认证提示；隐藏与当前模式无关的输入项。
- **改进以太网检测与网卡选择**：物理链路检测不再以获取 IP 为前提，避免 PPPoE / 802.1X 尚未认证时无法开始；指定以太网接口不存在时给出提示，不改用其他网卡或 Wi-Fi。macOS 有线网页认证在地址就绪后使用所选接口发送请求。
- **改进系统认证的自动重试与暂停**：首次满足条件时发起认证，设置超时及至少 60 秒的重试间隔；暂停或保存切换后的模式时取消待处理尝试。结合连接状态和联网检测显示结果，不将命令执行完毕直接视为认证成功。
- **修复 Windows 长时间后台运行后重新打开窗口可能白屏的问题**：恢复界面时保留当前页面、未保存的设置和密码，草稿仅在内存中保存；正常界面刷新不重复启动自动连接或重载学校认证页。
- **完善升级兼容与跨平台构建检查**：保留已有账号及配置，补充模式保存恢复、协议勾选、网卡选择、重试暂停和界面恢复回归；完善 Windows x64 / ARM64 原生安装检查，修正中文快捷方式路径的测试处理及测试换行兼容，并修正 macOS 在不同 Swift 工具链下的异步回调编译兼容问题。

## 使用

1. 打开对应系统版本；Wi-Fi 模式需要允许读取 Wi-Fi 名称的定位权限，有线模式无需此权限。
2. 在「校园网设置」选择连接方式：Wi-Fi 模式填写网络名称及网页认证信息；有线模式选择网页认证、PPPoE、802.1X 或学校客户端，按所选方式填写信息或先完成系统配置，保存。
3. 点击「立即连接」；网页认证在「上网认证」查看结果，系统认证及学校客户端按对应提示完成。
4. 需要持续运行时，在设置中启用自动连接。关闭窗口后程序留在菜单栏 / 系统托盘；选择「退出」后停止。

Windows 2.1.0 仅在自动连接开启且未联网时每 1 秒检查目标网络，首次满足条件立即连接，Wi-Fi 失败后最早 1 秒重试；只连接名称完全匹配且可见的目标，系统扫描及关联耗时可能超过 1 秒。ping 通后停止每秒 Wi-Fi 检查，仅保持 20 秒联网探测，确认掉线后恢复；关闭自动连接后停止定时检测。网页认证失败保留退避。macOS 2.0.3 发布版仍每 20 秒检查，两次连接尝试至少间隔 60 秒。两平台持续重试直到成功或用户暂停。Windows 数字验证码可在独立窗口核对识别参考并输入，其他验证码或多步登录仍需在学校页面完成。

认证信息只在已接入有线网络（有线模式）或当前 Wi-Fi 名称与设置匹配（Wi-Fi 模式），且网页协议 / 主机 / 端口与保存地址一致时自动填写。学校网页跳转到其他地址时，确认后更新设置再试。

## 平台差异

| 功能 | macOS | Windows |
| --- | --- | --- |
| 开放 Wi-Fi + 网页认证 | 支持 | 支持 |
| 有线网络 + 网页认证 | 支持；在设置中选择有线模式 | 支持；在设置中选择有线模式 |
| Wi-Fi 密码 / 企业认证 | 在应用设置中填写 | 先在 Windows 设置中连接并保存，应用复用系统配置 |
| 密码保存 | 用户目录本地文件，权限 600 | Windows 当前用户 DPAPI 加密 |
| 认证页面 | WebKit 临时会话 | WebView2 隐私会话，需要 WebView2 Runtime |
| 认证页直连 | 应用内代理按模式使用 Wi-Fi / 以太网 | 应用浏览器绕过显式 HTTP 代理；VPN 路由仍由 Windows 决定 |
| CPU | arm64 + x86_64 通用包 | x64 |

认证页无法访问时，可先完成校园认证再启用 VPN。本软件不会修改系统 VPN、DNS 或路由。它不保证自动适配所有学校的认证系统。
