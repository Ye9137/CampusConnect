# 校园Wi-Fi小助手 macOS 2.2.3 正式版

- 支持学校名单新增 **九江职业科技大学**。
- 改进采用命名 load 初始化的锐捷认证页，避免背景图片等装饰资源延迟阻塞认证初始化。
- 保留学校配置、加密参数及验证码就绪检查，防止迟到资源重复初始化。
- 升级保留原有账号与设置。

支持 Apple 芯片及 Intel Mac，系统要求 macOS 14 或更高。有线和无线请分别配置，网页没有服务选项时留空。

已完成核心及原生 WKWebView 自动化回归；学校实际认证仍需现场网络验证。Windows 特有的入口补充探测及运行时安装流程不适用于 macOS。继续采用项目非商业使用许可证及相应第三方许可证。
