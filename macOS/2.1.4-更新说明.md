# macOS 2.1.4

- 同步有线、无线独立配置与账号密码，切换时恢复完整资料及本次运行中的未保存草稿。已保存的当前配置自动迁移，重启后可恢复两套已保存资料。
- 未配置的模式不再填入默认校园名称、示例认证地址或另一模式的账号；清空无线名称不会切换为有线。
- 开启自动连接后，每 5 秒检查目标校园网络的联网状态，失败时重新查找目标网络并打开认证页面自动填写登录。验证码和其他需要人工处理的步骤继续等待手动完成。
- 关闭自动连接会停止定时任务；连接其他 Wi-Fi 时只读取当前连接标识，不扫描、不检查联网、不切换网络或打开认证页。网络检查前后及连接前会核对当前网络。
- 界面仅显示连接状态，保留手动刷新、立即连接和检查上网状态按钮。提供 Apple 芯片 / Intel 通用包，要求 macOS 14+。

两种模式修改后分别保存。此前已被旧版覆盖的资料需要重新填写。真实校园网断线重连、学校认证与多网卡环境仍需现场验证。
