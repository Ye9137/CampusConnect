# 校园Wi-Fi小助手 macOS 2.1.7

- 名称统一为“校园Wi-Fi小助手”，覆盖窗口、应用信息、托盘或菜单栏，以及 Windows 安装与快捷方式；保留已有配置和程序标识，升级无需重新填写账号。
- 新增认证错误弹窗：页面打不开、HTTP 错误、地址不匹配、缺少账号密码、服务选项未匹配、学校拒绝登录、未识别表单或登录按钮、协议未确认及脚本异常等情况，分别给出处理建议。
- 弹窗可进入“校园网设置”。同一次认证尝试只提示一次；成功登录、正常填写、等待验证码以及取消导航不作为错误弹出。
- “运营商 / 服务选项”输入框和下方说明明确提示：**如果认证网页没有需要选择的选项，请不要填写，否则会导致无法自动填写信息。** 网页确实需要选择时填写完整名称，保存后重新认证。
