## 2.0 正式版（2.0.0）

- 在「校园网设置」明确选择 Wi-Fi 或有线网络；有线无需填写 Wi-Fi 名称。旧版空名称配置继续按有线网页认证处理，修改后保存才会生效。
- 有线支持网页认证、PPPoE 宽带拨号、802.1X 系统认证及学校专用客户端。可指定以太网接口；指定接口不存在时不会改用其他网卡或 Wi-Fi。
- PPPoE 使用 macOS 网络设置中已创建并保存凭据的服务，实际网卡由该系统服务决定。系统拨号请求有取消与超时处理，请求返回不代表校园认证或联网已成功。
- 802.1X 使用 macOS 已安装的描述文件、证书和系统认证。请在「系统设置 → 网络 → 所选以太网 → 详细信息 → 802.1X」启用自动连接；手动连接在该页面完成。应用提供设置入口，不代替系统管理 EAP 或证书。[Apple 说明](https://support.apple.com/zh-cn/guide/mac-help/mchlp23882/mac)
- 学校客户端选择已安装的 macOS `.app`，已运行时不重复启动；不运行 Windows 的 `.exe`。账号、验证码和学校私有认证由客户端处理。
- 系统认证前先检测有线物理链路，不要求提前分配 IP；网页认证和联网检查需要所选网络就绪。网页访问绑定所选以太网接口，不回退到 Wi-Fi。外网 ping 仍采用系统路由，多网卡/VPN 需现场确认。
- 网页自动勾选可识别的登录必选框和协议项，保留网页事件、异步确认、来源校验及防重复提交。记住密码和推广订阅等可选项保留原状；拒绝勾选、验证码和额外字段交给用户处理。
- 使用中如遇到问题，请点击程序左下角「如果遇到问题请点击：!」的感叹号，查看联系方式并联系作者。

[更新说明](../2.0-更新说明.md)。真实校园 PPPoE、802.1X、学校客户端及网线拔插仍需现场验证。

## 1.5.2 有线模式

在「校园网设置」清空 **Wi-Fi 名称**，填写认证地址与上网账号密码并保存。接好网线后，点击「立即连接」或开启自动连接即可进行网页认证。无需无线网卡、Wi-Fi 密码或定位权限；填回名称即可恢复 Wi-Fi 模式。旧版配置保留原有模式。

自动填写仍检查认证网址的协议、主机和端口。没有有线连接时不提交认证。真实校园有线登录和网线拔插恢复尚需实测，详见根目录 [验证记录](../VALIDATION.md)。

## 1.5.0 正式版

支持服务选项，登录结果校验和百度 ping 检测。ping 通后显示“已经连接成功”，不再记录重复成功日志；失败时显示未联网，开启自动连接后按间隔重新认证。没有服务选项时留空。ping 使用系统路由，可能经过 VPN。

清理旧 HTTP 检测状态和无效计数，保留配置兼容、诊断、测试与许可证。最新验证范围见根目录 VALIDATION.md。

## 1.4.5 首次自动提交修复

- 首次填写后先完成输入框失焦与按钮准备，再检查并点击学校原有登录按钮。
- 对已识别 ePortal 页面，确认学校自己的登录处理已启动后才标记为已提交；首次点击没有进入处理函数时补发一次点击事件。
- 学校处理函数已经执行后不重复点击；异步登录等待确认，遇到验证码或校验提示交给用户处理。
- 页面刚开始加载时的临时脚本错误继续按间隔重试，不再提前放弃首次提交；就绪等待上限由 80 次调整为 200 次。
- 新增离线原生 WKWebView 回归测试，使用虚构账号，不请求学校登录接口。

## 1.4.4 网页认证与连接提速

- 统一使用学校网页自动填写认证，移除开发版接口认证选项；旧版账号、密码及网页设置继续保留。
- 同步密码框自动激活修复，在提交前核实账号和密码已正确填写。
- 启动或保存开启自动连接后立即尝试；已连接校园 Wi-Fi 时跳过全量扫描，并提前发起首次认证，减少等待时间。
- Wi-Fi 连接与认证失败后持续按间隔重试，直到成功、暂停或退出；验证码等特殊表单仍需手动完成。
- macOS 14+，Apple 芯片与 Intel 通用包。尚未完成真实校园网端到端登录及耗时实测。

## 1.3.4 连接恢复与即时导航

- 两平台均使用即时悬停选择，内容推进动画为 280ms；认证准备、SSID 查询和联网检查不阻塞导航。
- 学校认证初始化在 DOM 就绪时开始，无须等背景图片；参数和加密公钥就绪后以 150ms 检查间隔尽早填写、提交，提交后 1 秒开始检查互联网。

- 侧边栏移入即切换，无悬停计时器；页面常驻，推进动画仅作用于内容，快速切页不会重新挂载认证浏览器。
- 保持 Wi-Fi 连接时每 20 秒继续检查互联网，严格校验两个不同站点的响应；探测走物理 Wi-Fi 并禁用缓存和重定向。
- 认证失效后自动重新认证；网络超时连续两次才触发恢复，重试间隔逐步从 60 秒增加至最多 300 秒。手动填写、特殊表单不反复刷新。

## 安装与使用

1. 下载并解压 `CampusConnect-macOS-universal-2.0.3.zip`。
2. 将 `CampusConnect.app` 拖到「应用程序」，双击打开。
3. 此包使用本地临时签名，未经过 Apple Developer ID 签名和公证。若系统拦截，请确认下载来源后，在「系统设置 → 隐私与安全性」中允许打开。
4. 在应用「网络概览」点击授权定位，允许读取 Wi-Fi 名称。
5. 在「校园网设置」填入校园账号密码并保存，点击「立即连接」。默认不自动连接，可自行开启。
6. 关闭窗口后保留在菜单栏，在菜单栏选择退出可完全关闭。

账号密码仅保存于本机：`~/Library/Application Support/CampusConnect/configuration.json`。延续原版的本地明文存储方式，配置目录权限为 700，文件权限为 600，不访问系统钥匙串。请勿分享该文件。

## 从源码构建

```sh
xcode-select --install
zsh macOS/source/build.sh
```

请在仓库根目录执行。输出 `macOS/CampusConnect.app`，包含 `arm64` 和 `x86_64` 两种架构。运行检查：

```sh
zsh macOS/test.sh
zsh macOS/test-webkit.sh
codesign --verify --deep --strict macOS/CampusConnect.app
lipo -archs macOS/CampusConnect.app/Contents/MacOS/CampusConnect
```

应用内部认证连接可绑定物理 Wi-Fi，适用于部分 VPN 干扰校园认证的情况。并不修改系统 VPN 配置。验证码、额外运营商账号及未识别的特殊控件仍需手动处理。
