# macOS 2.1.3

- 同步当前认证设置精简：自动识别登录表单，不再使用旧配置中的自定义 CSS 选择器；账号、密码、网络与运营商设置继续保留。
- 增加通用验证码字段检测，未填写时暂停自动提交，提示在学校网页中手动输入英文字母及数字。保持学校输入框、大小写与原有登录事件。
- 保留运营商选择、协议确认、来源校验和防重复提交；不加入验证码自动识别或独立识别窗口。
- 更新版本显示和支持学校说明，提供 Apple 芯片 / Intel 通用应用，要求 macOS 14 或更高版本。

离线原生 WKWebView 测试覆盖空验证码不提交、手动字母数字输入、大小写保留及防重复提交。实际学校认证、断网恢复与多网卡环境仍需现场验证。
