# Windows 2.1.2 正式版

- 移除“高级设置 · 特殊认证页面”，以及账号输入框、密码输入框、登录按钮三个自定义 CSS 选择器。
- 认证表单统一使用自动识别。旧配置的选择器字段不再生效，下次保存时不再写出；已有账号、密码、运营商、认证地址和“自动填写后点击登录”偏好保留。
- 同步清理草稿恢复和认证提示对已删除功能的引用。
- 支持学校名单新增 **三峡大学**。
- 固定模型 JSON 文件的跨平台换行格式，避免 Windows 从源码构建时字典校验值变化；构建工具下载增加重试。
- 保留 2.1.1 的每秒刷新按钮防闪烁、入口跳转、循环重试停止、运营商选后收起，以及既有学校适配和本地验证码模型。

本次发布 Windows x64 安装包和源码，macOS 安装包保持现有版本。退出托盘中的旧程序后安装，原有配置继续使用。

本地核心、设置页面、草稿恢复、按钮稳定、跳转和验证码回归，以及两平台源码编译检查已通过。离线和构建结果不代表真实校园网络登录或模型准确率验证；云端原生检查状态以对应 GitHub Actions 记录为准。
