# CampusConnect 2.1.5 正式版

本次更新 Windows 与 macOS，重点修复部分校园宽带页面“账号、密码、验证码和登录按钮均无法识别”的问题。

## 更新内容

- **支持框架内登录页面**：新增对同源 `frameset / frame / iframe` 及嵌套子页面的识别，入口页只有框架时，也能找到实际的登录表单。
- **适配 CMCC 校园宽带旧式页面**：修复 `scunioncmccgxsd76.jsp → unionautologin.do` 页面中的密码提示层、真实密码输入框及图片式登录按钮识别，沿用学校原有的显示密码和登录事件。
- **修复验证码框识别**：支持该页面的 `ps / psNum` 输入框与邻近验证码图片，将“请输入验证码”视为待填写提示；不再把该页面的“最多 6 位”误当成“必须 6 位”。Windows 的验证码窗口可在子页面读取和回填，保留字母、数字及大小写；macOS 在学校页面手动输入验证码。
- **完善框架填写边界**：外站、沙箱隔离、隐藏或零尺寸框架不自动填写；多个可用登录框架并存时停止自动填写。验证码变化、账号变化或子页面更换后，旧验证码不能继续提交。
- **保留原有适配**：延续已有运营商菜单、ePortal、zPortal、入口跳转、有线 / 无线独立配置及 5 秒自动恢复行为。

## 使用提示

该 CMCC 页面没有运营商选择控件，请将设置中的“运营商 / 服务选项”留空。保存校园网络当前打开得到的完整认证地址；链接中的 `wlanuserip` 可能随网络变化，旧地址失效时请重新探测。

验证码需核对原图后输入，不承诺识别准确率。升级前请退出旧版本；原有设置继续使用。

## 安装包

- Windows：x64 Setup.exe，包含 .NET 运行时和本地验证码模型；缺少 WebView2 或 Visual C++ 运行库时由安装器按需从微软下载。
- macOS：Apple 芯片 / Intel 通用 ZIP，需 macOS 14 或更新版本。
- 另附完整源码 ZIP 与 `SHA256SUMS.txt`。
