# Windows 2.1.1 正式版

- **修复每秒刷新造成的按钮闪烁**：后台检测及自动重连不再反复禁用全部按钮；手动刷新或连接仍保留操作锁。信号、目标网络和连接状态变化时原位更新列表，保留按钮、键盘焦点、悬停及按下状态，刷新期间的点击不会因按钮被替换而丢失。
- **支持认证入口跳转**：先访问学校入口（例如 `http://1.1.1.1`），再跟随初始自动跳转到实际认证页；识别登录表单后固定本次来源，再填写和调用学校原有登录事件。设置保留入口，不保存跳转网址中的临时参数。
- **停止地址异常造成的循环重试**：地址不匹配、重复跳转、跳转超限、加载或表单识别失败时暂停自动重开。处理后点击“立即认证”可重新开始。
- **运营商选中后收起选项**：手动与自动选择均会在确认选中后收起列表，露出连接按钮；再次点击仍可展开切换。
- **学校名单更新**：新增佛山大学、广东海洋大学，保留内蒙古工业大学、上海东海职业技术学院等既有适配。
- 保留 2.1.0 的 zPortal 隐藏密码框、二维码按钮排除、动态验证码及本地 ONNX 验证码模型。

本次发布 Windows x64 安装包及源码，macOS 安装包保持现有版本。退出托盘中的旧程序后运行安装包，已有配置继续使用。

完成本地核心测试、浏览器按钮交互与多步跳转复现、登录回归、Windows x64 构建及安装包检查。离线测试使用合成页面和虚构账号，不能替代各学校的真实校园网验证；验证码模型准确率仍需核对原图，不保证识别正确。云端原生构建和安装器检查结果以该版本对应的 GitHub Actions 记录为准。
