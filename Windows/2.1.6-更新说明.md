# CampusConnect 2.1.6 正式版

本次同步更新 Windows 与 macOS，补充广东海洋大学支持说明，并统一默认空白配置。

## 更新内容

- **支持学校名单补充（2026-10-22）**：加入 **石家庄铁道大学**。
- **广东海洋大学支持说明**：根据用户反馈补充配置提示。该校页面没有运营商 / 服务选择控件时，将对应设置保持空白，按学校页面完成网络使用承诺与登录。
- **填写项默认全部为空**：新安装、未配置的有线 / 无线模式，以及旧配置中缺失的填写字段，均不预置 Wi-Fi 名称、账号、密码、认证地址、运营商 / 服务选项、以太网接口、PPPoE 名称或学校客户端路径。macOS 的 Wi-Fi 企业账号也默认留空。
- **移除旧学校回退值**：不再在数据模型和配置读取时补入固定学校 Wi-Fi 名称或示例认证地址；运营商输入提示明确为可留空。已经保存的真实配置与密码继续保留，有线 / 无线分别恢复各自设置。
- **修复 Windows 上网承诺框被跳过**：服务选项不匹配时仍检查独立的“本人承诺……”必选项，再提示修正服务选项；保留学校的点击与校验事件，不修改“记住密码”。服务未选好、协议被禁用或学校拒绝勾选时，仍停止自动登录。

## 使用提示

安装前退出托盘 / 菜单栏中的旧版本。首次使用请自行填写当前学校的网络信息；运营商 / 服务选项仅在认证页面确实提供该控件时填写网页上的完整名称，没有该选项时保持空白。

“默认空白”作用于新配置和未填写字段，不会清空你已保存的账号、密码和网络信息。若旧配置里曾手动填过运营商，且学校网页没有该选项，请手动清空后保存。

## 安装包与验证

提供 Windows x64 安装包、macOS Apple 芯片 / Intel 通用 ZIP、完整源码和 SHA-256 校验文件。macOS 需 14 或更新版本；Windows 缺少 WebView2 或 Visual C++ 运行库时，由安装器按需从微软下载。

已通过本地默认空白、缺失配置回退、有线无线配置保留、协议勾选和原有登录页面回归。本版本正式附件使用同一提交的 GitHub Actions 原生构建，发布前检查 macOS、Windows x64 / ARM64 构建以及 Windows 安装、修复、升级、快捷方式和卸载流程。

广东海洋大学可用反馈来自用户；本机未在该校网络提交账号密码。自动化测试使用本地页面和虚拟凭据，不代表所有学校认证均已实网验证；Intel Mac 实机运行仍未验证。
