# 校园Wi-Fi小助手 Windows 2.2.1-preview.1 测试版

修复新疆大学所提供登录页中，账号密码填写后无法识别“登录”按钮的问题；识别“请选择出口线路”提示，避免在尚未选择线路时提交。

1. 从系统托盘完全退出旧版，再运行新版安装包。升级保留原有设置。
2. 启动后确认页脚为 v2.2.1-preview.1。
3. 在软件设置的“运营商”栏填写 `中国联通`，与本次页面的实际选项保持一致，保存后重新认证。也可先在网页中手动选好出口线路。
4. 网页若显示验证码，按提示完成后登录。

本次按提供的 HTML 结构适配，并保留学校网页原有点击与线路切换事件。未获取学校实际 JavaScript 和认证响应，未在真实校园网或 Windows WebView2 上验证登录。本包用于现场测试，不代表新疆大学认证已验证通过。

若仍停在登录页，请提供截图、软件日志、是否已选中出口线路，以及同机 Edge 能否正常登录。不需要提供账号密码。
