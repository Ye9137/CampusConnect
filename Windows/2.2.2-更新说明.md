# 校园Wi-Fi小助手 Windows 2.2.2

- 安装包内置微软官方 .NET 10.0.14 桌面运行时（x64），缺少兼容版本时自动离线安装。
- 已安装同架构 10.0.14 或更高 10.0 正式版本时跳过，不重复安装。
- 运行时补全失败或取消管理员授权时停止安装，保留旧版本程序及账号配置。
- 主程序仍安装到当前用户；系统运行时安装可能提示管理员授权，不强制重启。卸载助手保留共享运行时。
- WebView2、Visual C++ 运行库缺少时仍需要联网补全。

本次调整 Windows 安装流程，macOS 保持 2.2.1。学校现场登录效果需在实际校园网验证。继续采用项目非商业使用许可证及相应第三方许可证。
