# 2.1.10-preview.5 Windows 本地测试版

针对截图“此网站不支持安全连接，因为你处于 InPrivate 模式”的 HTTP 拦截提示修复。

本次修改
认证网页使用本应用独立的普通浏览器配置，不再使用 InPrivate 模式打开学校 HTTP 页面。
在小助手自己的 WebView2 运行环境中关闭 HTTP 自动升级和默认 InPrivate HTTPS-First 拦截，使学校提供的 HTTP 入口、跳转和后续表单可以继续打开。
正常 HTTPS 地址仍按 HTTPS 访问，证书校验与 HSTS 机制保留；没有忽略证书错误，也没有修改系统 Edge 的全局设置。
学校页面可能在本应用的独立配置中保留 Cookie 和网页会话。浏览器自动保存密码仍关闭，应用原有账号密码配置保留。
沿用 preview.4 的“Ping 通但仍未完成网页认证”识别、实时入口跳转与自动填写修复。

安装与测试
先在系统托盘中完全退出旧版，再运行安装包；不要只关闭窗口。
重新启动后确认页脚为 v2.1.10-preview.5，再点击“立即认证”测试 HTTP 入口。
升级不会修改保存的账号密码和目标网络。网页没有运营商 / 服务选择框时，对应设置保持空白。
本包仅本地交付，未推送、未发布，macOS 未修改。

验证范围
核心检查 2545 项通过。已用生产浏览器参数验证 HTTP 跨主机跳转、表单显示、自动填写和点击，确认未发起强制 HTTPS 升级；自签名 HTTPS 证书仍被浏览器拒绝。
Windows 原生测试已加入独立普通配置的读取验证，并已编译通过。当前环境为 Mac，本次未运行 Windows 原生 WebView2 / Edge，因此截图中的提示是否消失和真实校园网登录仍需在反馈电脑确认。
