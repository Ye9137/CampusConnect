# Windows 2.1.6-preview.1 · 上网承诺框修复测试版

本次仅修改 Windows，未上传、未创建正式发布，macOS 代码保持 2.1.5。

截图顶部提示“未找到或未能选中填写的服务选项”，旧逻辑在此提前退出，导致下方“本人承诺……”复选框根本没有执行勾选逻辑。现将服务选择结果暂存，在检查承诺框后再决定是否暂停登录。

- 保留学校服务选择事件先执行、承诺框随后检查的顺序，避免服务切换重置已勾选状态。
- 只处理上网承诺 / 必需协议项，保留“记住密码”等其他选项的原状态。
- 服务选项不匹配时仍会暂停登录，但不会跳过独立的上网承诺框。必选框被禁用或被学校事件拒绝时仍不提交；多次检查不会反复取消勾选。

测试：已先复现旧版本“服务错误返回后承诺框未勾选”，修复后 93 项协议检查通过；Windows 核心 2221 项、框架页 65 项和原有 ePortal、zPortal、验证码、服务菜单及初始化回归通过，安装器文件清单检查通过。

使用：先完全退出旧版，再安装此测试包，确认显示 2.1.6-preview.1。截图页面若没有运营商 / 服务选择控件，请将设置中的“运营商 / 服务选项”留空后重新认证。服务仍不匹配时承诺框会勾选，但不会绕过该错误登录。

限制：当前机器无法读取截图中的校园内网页面，测试使用截图文字构造的离线页面及虚拟凭据；没有向真实学校提交账号密码。本包为 macOS 上交叉构建（未启用 ReadyToRun），尚未进行本次原生 Windows 安装及真实校园网页验证，需要现场确认。
