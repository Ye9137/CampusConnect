# Windows 2.1.4

- 有线、无线分别保存完整配置，包括认证地址、账号、密码、运营商、无线连接选项和有线认证方式。切换时恢复对应信息，未保存草稿在当前运行期间保留，界面恢复也不丢失两套草稿。
- 已保存的当前配置自动迁移，Windows 两套密码继续使用 DPAPI 加密。首次使用或尚未配置的模式保持空白，不填入 HNPI-STU、示例地址或另一模式的账号；无线名称清空后仍保持无线模式。
- 开启自动连接后，每 5 秒检查所选校园网络的联网状态。检查失败时重新查找目标网络、打开已保存认证页面并自动填写登录；同时保留验证码、协议和需要人工处理时的暂停保护。
- 关闭自动连接后停止后台任务。已连接其他 Wi-Fi 时只读取当前连接标识以便发现返回目标网络，不扫描、不检查联网、不抢占该网络、不打开认证页。手动操作仍可使用。
- 界面显示连接成功、未连接成功或正在恢复，不显示探测命令和目标站点。后台检测不反复禁用按钮。

两种模式修改后分别点击保存。此前已被旧版覆盖且未留存的另一套配置无法凭空恢复，需要重新填写一次。实际校园网断线、重连与学校登录仍需现场验证。
