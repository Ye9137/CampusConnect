校园网络

网络连接方式
修改连接方式后请点击保存，网络概览显示已保存的配置。
先在 Windows 创建 PPPoE 宽带连接并保存账号密码，再选填同名连接。此模式复用系统保存的凭据，实际网卡由该 Windows 宽带连接配置决定。
先按学校要求在 Windows 的以太网属性中配置 802.1X、证书及凭据，并启用 Wired AutoConfig 服务。助手向所选接口发起重新认证；Windows 要求权限时，请按系统提示处理。
连接时启动该客户端，客户端已运行时不重复启动。客户端内的登录、验证码与学校私有协议由客户端处理。
HNPI-STU 默认按开放网络处理；学号和密码在下方网页认证中填写。

连接后进行网页认证

填写认证网页中的完整选项名称，例如中国移动、中国联通、中国电信或联通接入服务。网页需要选择运营商时请填写，保存后重新认证；网页没有此选项时留空。
高级设置 · 特殊认证页面
留空时自动识别。若学校页面包含验证码、额外运营商账号或特殊表单，可先手动完成，再按页面调整。
密码保存在本机
修改后点击保存。下次打开会沿用已保存的账号和密码。
