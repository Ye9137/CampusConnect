# Windows 2.1.3

- 修复验证码窗口只接受数字的问题：手动键入、粘贴、确认和网页回填均支持英文字母及数字，原样保留大小写。
- 页面未明确限定纯数字时，使用手动输入提示，不运行数字识别或显示“未识别出数字”。页面明确声明数字格式时保留数字约束与既有识别参考。
- 已声明长度的验证码继续按页面长度校验；长度未知时手动点击登录或按回车。原图变化、来源不符、重复提交等保护继续生效。
- 本次同时提供 macOS 2.1.3 通用版。macOS 使用学校原有网页输入验证码；空验证码会等待手动补充，不自动消耗登录次数。

字母数字验证码请根据图片手动输入。本版本没有新增字母验证码自动识别能力，也没有完成南京工业大学新版页面的真实校园网端到端登录验证。
