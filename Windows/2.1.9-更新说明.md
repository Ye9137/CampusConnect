# 校园Wi-Fi小助手 Windows 2.1.9 正式版

- 支持学校名单补充 **河南工业大学**。

- 新增 **河南科技大学**账号登录页面适配，识别“立即登录”按钮，等待学校配置及认证上下文就绪后再提交。
- 跟随本次认证窗口实际到达的登录页，支持入口与落地页之间的域名、HTTP/HTTPS 和端口变化，保留原有入口设置。
- 保留学校原有密码校验和登录流程；识别成功、拒绝、验证码及请求失败，拒绝后暂停自动重试。
- 学校返回 E20027 等错误码时保留错误码，不推断其具体含义。河南科技大学已完成离线适配，**实网登录仍待验证，尚不能确认 E20027 已消除**。

- 支持在现有验证码窗口按原图确认英文字母和数字，保留大小写与学校生成的验证码标识。
- 提供 Windows x64 安装包，升级保留已有配置。
