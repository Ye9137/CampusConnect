# Windows 2.0.3-local.6 · 新增上海东海职业技术学院登录支持

本次更新 Windows x64，沿用已确认可用的 2.0.3-local.6 安装包。

- **新增上海东海职业技术学院登录支持**：适配统一身份认证页面及动态出现的数字验证码。
- **新增验证码本机识别**：提取验证码原图，突出显示识别数字，支持一键复制；识别失败时可根据原图手动输入。
- **新增独立验证码输入窗口**：支持粘贴，输入完成后按回车或点击登录；网页明确规定验证码长度时，输满后自动确认。上网认证页新增「输入验证码」入口。
- **目标网络改为每 1 秒检测一次**：启动后立即检查，持续等待并尝试连接目标 Wi-Fi，改善开机时连接不及时的问题。

识别结果请核对原图。数字识别使用 Windows 自带 OCR，需要系统具备可用识别语言；图片不上传。
