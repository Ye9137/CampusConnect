# 河南师范大学图标运营商适配

适用页面：`hsd_pyh_pc_portal_skin-2` 老用户登录区。Windows、macOS 同步调整。

设置中的“运营商 / 服务选项”可填写：

| 运营商 | 支持填写 | 页面内部值 |
| --- | --- | --- |
| 中国移动 | 移动、中国移动 | yd |
| 中国联通 | 联通、中国联通 | lt |
| 中国电信 | 电信、中国电信 | dx |

页面只在图标中显示运营商，原来的文字匹配无法识别。新增匹配同时核对登录区、账号密码字段、单选框名称/值以及对应图标样式，继续通过页面的点击事件选择，随后校验选中状态；不直接拼接账号后缀，也不调用或替换学校认证接口。

运营商设置留空时保持页面原有选择，不自动选择任何运营商。根据所提供页面公告，临时账号可不选择运营商，办理成功后再填写对应运营商。

验证记录：

- 使用提供的账号登录区 HTML 制作离线夹具，使用模拟事件处理器观察选择与提交；附件未包含外部 common.js/portalUtil.js 的实现。
- Windows 生产模板和 Swift 编译生成的 macOS 脚本各通过 83 项浏览器检查，覆盖三运营商的全称/简称、选择事件、提交去重、仅填写模式、临时账号、保留手选、隐藏/禁用/重复/拒绝选择、图标和值不符、其他表单隔离及来源校验。
- 现有 ePortal、运营商菜单收起、服务选项提示和通用脚本回归通过。
- 本记录不表示真实校园网认证已通过；须在学校网络内验证。
