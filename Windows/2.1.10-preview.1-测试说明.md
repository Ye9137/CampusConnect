# Windows 2.1.10-preview.1 重连修复测试版

- 修复临时网络失败、登录结果超时或校验中断后，认证被永久置为等待人工处理的问题。
- 临时网络错误、HTTP 408/429/5xx、学校认证请求的网络失败、配置加载未就绪及脚本执行中断允许恢复自动重试。下一轮先检查实际联网状态，至少间隔 5 秒，避免重叠提交。
- 认证页面进程恢复后，原先正在进行的自动认证可在联网复查和冷却后重试；已暂停的验证码及人工处理状态保留。
- 学校明确拒绝登录、账号密码缺失、服务项/协议需确认、证书或配置错误、提交状态不明确等情况仍等待人工处理。
- 关闭自动连接或自动提交时不会自行恢复提交。本次仅修改 Windows，不更新正式发布。

验证使用离线端点和虚构账号，包含核心策略与生产认证控制器的 Windows 原生测试、浏览器回归及安装生命周期检查。真实校园断网重连仍需在反馈电脑现场验证。

使用：退出旧版后运行测试安装包，确认底部版本为 2.1.10-preview.1；在校园网络上测试断网后的自动恢复，并核对验证码和明确拒绝提示是否继续暂停。
