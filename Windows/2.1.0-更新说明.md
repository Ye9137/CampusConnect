# Windows 2.1.0 正式版

## 新增功能

- **新增内蒙古工业大学登录支持**：适配提供的 zPortal 页面结构，先激活密码提示框，再填写真实密码框，调用学校原有登录按钮；避免误选二维码登录。
- **新增上海东海职业技术学院登录支持**：适配统一身份认证页面和动态出现的数字验证码。
- **新增本地验证码识别模型**：随包提供 ddddocr 模型，通过 ONNX Runtime 在本机运行，无需 Python，不上传验证码图片；Windows 系统 OCR 作为后备。
- **新增验证码独立输入窗口**：提取原图、突出显示数字识别参考，支持一键复制、粘贴和手动修改；输入后通过学校原有按钮继续登录。页面明确规定长度时输满后自动确认，否则按回车或点击登录。识别失败仍可手动输入。

## 修复与改进

- 自动连接开启且未联网时，每秒检查目标网络，启动后立即检查。
- 修复每秒后台检测造成「立即连接」「刷新网络」等按钮反复闪烁、变灰的问题，相同状态不重复刷新界面。
- 关闭自动连接后停止定时检测；ping 通后停止每秒 Wi-Fi 检查，仅每 20 秒探测联网，确认掉线后恢复每秒检查。手动刷新和连接仍可使用。
- 识别 zPortal 隐藏密码框、验证码提示文字和已有登录结果页，保留页面自身的认证流程。

## 内蒙古工业大学设置

高级选择器可留空自动识别；如需手动指定，账号为 `#user_name`，密码为 `#password`，登录按钮为 `#login_submit`。`#tx` 仅用于显示密码提示，请勿将其设为密码输入框。认证地址请使用学校实际登录页面，账号及会话参数不会随软件发布。

## 安装与验证范围

本次仅更新 Windows x64，macOS 保持现有版本。退出系统托盘中的旧程序后运行新安装包；已有设置继续使用。

首次安装若缺少 WebView2 或 Microsoft Visual C++ 运行库，需要联网补全，可能出现管理员授权提示。验证码模型随安装包提供，识别过程在本机完成；识别结果应核对原图。

2.1.0 整合此前 Windows 本地更新并使用正式版号。本轮完成编译、打包和静态文件检查；按用户要求，未运行模型推理、Windows 原生界面或真实校园网测试。新增学校适配依据提供的页面结构，尚未实网验证，暂不提供识别准确率提升数据。
