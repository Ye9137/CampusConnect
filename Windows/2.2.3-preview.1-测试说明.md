# 校园Wi-Fi小助手 Windows 2.2.3-preview.1

- 兼容通过原生 doauthen 登录、但不提供 AuthInterFace.login 的锐捷 ePortal 页面。
- 填写锐捷账号密码后触发学校原有 keyup 处理，再调用页面自己的登录按钮。
- 未发现实时入口时，增加百度 HTTP 与已保存 ePortal 网关首页探测，保留网关返回的有线／无线参数。
- 不将百度自身跳转、成功落地页或不带当前参数的 ePortal 入口当作新登录地址。
- 保留手动登录、验证码输入、运营商选择、重复提交保护及内置 .NET 离线运行时。

已复现离线页面中原版本无法提交而参考程序能够提交的差异；学校实际页面、成功认证地址及现场登录仍需验证。本版本用于验证登录兼容修复，不代表已经完成该校实网认证。
