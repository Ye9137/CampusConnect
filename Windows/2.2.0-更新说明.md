# 校园Wi-Fi小助手 Windows 2.2.0 正式版

- 支持名单新增 **潍坊学院**、**陕西国防工业职业技术学院**。
- 自动识别陕西国防工业职业技术学院的 `#submit` 登录按钮，无需手动修改 CSS；仅选择账号密码所在表单中唯一、可用的控件，保留网页原事件。
- 适配提供的 Gportal 页面中带空格的“登 录”按钮，限定登录表单，等待原登录脚本与加密参数就绪，观察原请求的成功或拒绝结果。
- 支持跨主机、端口及 HTTP/HTTPS 的认证跳转，保留已保存的入口与账号配置；验证码等需要人工处理的步骤继续暂停等待。
- 改进 HTTP 认证页面兼容、Ping 通但仍需认证时的探测、取消与过期导航提示。
- 提供 Windows x64 安装包，升级保留配置。

学校支持名单按用户反馈更新。离线页面与原生浏览器回归不等同于两所学校的实网认证验证。
