# 校园Wi-Fi小助手 Windows 2.1.8 正式版

- 填写的运营商 / 服务选项无法匹配时，弹窗区分未识别到选择控件、未找到完整匹配名称、网页未确认选中三类原因，并显示填写的服务名称供核对。
- 弹窗提供“上一步 / 下一步”的分步处理向导。点击“打开对应设置”可进入校园网设置、滚动并聚焦相关输入框，保留原填写供手动修改。
- 页面暂未加载出服务项时保留有界等待；每次认证尝试只提示一次，修正并保存后点击“立即认证”重试。
- **如果认证网页没有需要选择的选项，请不要填写，否则会导致无法自动填写信息。** 未识别到控件也可能是页面未加载完成或结构暂不支持，请先查看学校网页确认；需要选择时填写网页显示的完整名称。
- 提供 Windows x64 与 ARM64 安装包，升级保留已有配置。沿用“校园Wi-Fi小助手”名称和已有学校适配。

本次标签的 GitHub Actions 覆盖核心与浏览器回归、Windows 原生向导以及安装、修复、升级和卸载检查。真实校园网登录、动态服务菜单及网络恢复仍需在对应学校现场验证。
