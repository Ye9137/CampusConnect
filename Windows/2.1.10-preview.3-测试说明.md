# 2.1.10-preview.3 Windows 本地测试版

本包仅在本机生成和交付，未推送源码，未上传安装包，未创建 GitHub Release。macOS 未修改、未打包。

本次修复
1. 通用按钮识别支持“立即登录 / 立即登陆”，兼容动态加载表单及框架 input/change 事件，仍通过学校网页原来的按钮处理登录。
2. 已确认联网后，使此前尚未结束的自动填写和结果检查失效；后续落地页加载失败不再覆盖成功状态或重新弹出失败向导。
3. 联网成功、认证成功或停止后，已经显示的旧错误向导自动关闭；过期向导不会再将界面带到设置页。
4. 真正加载失败时，向导显示具体 HTTP 状态或 WebView2 错误标识，便于进一步排查。

使用
退出旧版（包括系统托盘中的程序），再运行安装包，确认页脚显示 v2.1.10-preview.3。
认证地址应保留学校登录入口。截图中的 110.184.24.61/portal/entry/pc/authenticate... 是认证页，www.189.cn/web/ 是后续网站，不要将后者保存成认证入口。学校生成的跳转和会话参数继续由网页处理。
网页没有运营商选择框时，“运营商 / 服务选项”保持空白。
先观察能否自动填写并点击“立即登录”，再确认联网后错误向导是否消失。若仍失败，请保留向导显示的具体错误码。

验证与边界
Windows 核心检查 2524 项通过；动态表单、立即登录按钮、手动模式、重复提交、连续跳转、框架输入事件、ePortal、zPortal、账号门户、验证码及协议等 Chromium 离线回归通过。
Windows 应用及两组原生测试程序均在 Mac 上交叉编译。原生 Windows 弹窗 / WebView2 测试没有在本次环境运行，安装与卸载也尚未在 Windows 实机运行。
安装包进行压缩完整性检查、解包和全部载荷逐字节比对，校验值见 SHA256SUMS.txt。
原始三份附件是网页 JavaScript，并非运行日志；目前只能确认上述代码问题，尚不能确定截图当时具体的页面加载错误。学校真实登录和断线重连仍需在现场网络确认。
