# 2.1.10-preview.7 Windows 本地测试版

新增陕西国防工业职业技术学院登录按钮适配，选择器由使用者反馈为 `#submit`。

软件会在所选账号密码表单中优先查找唯一、可见、可用的 `#submit` 登录控件，不依赖按钮文字。继续点击学校原控件，保留原事件、加密和请求流程；不需要手动填写按钮 CSS。
注册等其他表单内的同名按钮、隐藏 / 禁用 / 重置控件和多个无法唯一判断的同名按钮不会被此规则点击。手动填写模式不提交，验证码仍须完成后才能登录。
验证码窗口回填后的按钮选择采用同样规则。原 Gportal、HTTP 入口兼容和断网认证探测修复继续保留。

先从系统托盘完全退出旧版，再安装本包。启动后确认页脚为 v2.1.10-preview.7，检查保存的账号、密码和学校认证地址，再点击立即认证。升级保留配置。

专项检查使用虚构地址和凭据，验证生产嵌入脚本的填写、原事件点击、表单隔离及验证码回填提交。学校选择器来自用户反馈，当前 Mac 环境无法运行 Windows WebView2，真实学校认证仍需现场确认。
仅 Windows 本地交付，未推送、未发布，macOS 未修改。
