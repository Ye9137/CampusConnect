# Windows 2.0.3-local.8 · 本地验证码模型与登录兼容更新

- **新增本地验证码识别模型**：随包提供 ddddocr 模型，使用 ONNX Runtime 在 CPU 上运行，不需要安装 Python，不上传验证码图片。系统 OCR 作为后备，识别数字仍需核对原图后复制或输入。
- **修复 zPortal 密码框无法填写**：识别隐藏的真实密码框，触发页面原有提示框切换事件，并选择账号密码登录按钮，避免误点二维码登录。兼容“验证码”提示值和已有登录结果页。
- **调整自动检测条件**：关闭自动连接时停止后台定时检测；开启自动连接且 ping 通后停止每秒 Wi-Fi 检查，只保留每20秒联网探测。确认掉线后恢复每秒检查。手动刷新和连接仍可使用。
- **保留按钮防闪烁修复**：后台读取静默进行，相同状态不重复刷新界面。

仅更新 Windows x64。模型约13.6 MB，随安装包提供；首次安装若缺少 Microsoft Visual C++ 运行库，需要联网补全，可能出现系统管理员授权提示。

本轮完成编译、打包及文件/语法检查，按用户要求未运行模型识别、Windows 界面或真实校园网测试；暂不提供准确率提升数据。
