# 2.1.10-preview.2 跳转登录测试版

Windows 和 macOS 均关闭应用的防跳转限制。Windows 版保留 preview.1 的临时错误自动重连修复。

- 移除跳转次数、30 秒跳转时限、重复地址及 HTTPS 转 HTTP 的应用限制，不再因此弹出“认证入口反复跳转或等待超时”或暂停登录。
- 根据当前页面继续识别、填写和提交登录表单，保留主机、端口、路径与学校会话参数；临时地址不自动写回设置。
- 过渡页未出现表单时继续等待，不再因原来的表单等待时限中止认证。
- 学校打开新认证窗口时在应用认证视图中继续；首次填写或提交后跳到下一张表单也可继续。关闭自动提交时仍只填写。
- macOS 校园直连桥接允许跳转及其他主机提供的认证页面资源和请求。

退出旧版后安装 / 打开新版，确认底部版本为 2.1.10-preview.2。使用原来的校园网配置测试跳转及登录。错误密码、学校明确拒绝、需要人工验证码等情况仍按网页要求处理；登录成功、停止或失败后清除本次内存中的密码。

验证包含虚构账号、仅本机端点的连续 HTTP / 脚本跳转、跨域表单、慢速过渡页、认证新窗口、二次登录表单和手动模式。真实学校登录效果需要在反馈电脑现场确认；服务器本身超时或不可达时仍可能加载失败。
